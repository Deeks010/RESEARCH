## Read the visual reports

GitHub displays HTML source rather than running these reports. Download this repository using **Code → Download ZIP**, extract it, and open [the local start page](index.html) in your browser. Keep the folders together so links and data downloads work.

The HTML reports work offline. External evidence links require internet. No hosting or GitHub Pages deployment is included.

## Evidence boundaries

- Research prospects are not confirmed buyers. No outreach was sent.
- Publicly published email addresses do not prove delivery or exclusive access by the named person.
- Vendor claims, source observations, estimates and recommendations are distinguished in the reports.
- The website project remains a text-based review. Homepage screenshots and visual/mobile assessments could not be completed because browser access was unavailable.

Original research notes, structured data, supporting evidence and report-building scripts are retained in their respective project folders. The original unrelated application project is not included.
